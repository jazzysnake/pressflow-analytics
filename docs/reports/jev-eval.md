# Jev (TypeSafe API) sentiment evaluation (T3.6)

Generated by `pressflow.eval_jev` from `data/processed/jev_scores.parquet` and `eval/eval_set.csv` (201 consensus posts). Metrics computed with the T3.3 functions in `pressflow.select_model`; baselines copied from `docs/reports/model-selection.md`.

## Method

Each post's text was sent to `POST https://api.typesafe.ai/v1/systemone` with `model="jev-latest"` and a single `choice` question answered over the options `bull` (expects rise / buy), `bear` (expects fall / sell) and `neutral` (no directional view). Jev's `probabilities` were normalised to `p_bull / p_bear / p_neutral` (sum = 1) with `net = p_bull - p_bear`; the hard class is the argmax, matching the off-the-shelf pipeline. Requests were sent with a ~0.2 s delay and retried on 429/5xx with exponential backoff.

## Verdict

**REJECT Jev — keep hts5**

Jev directional macro-F1 0.566 vs hts5 0.230 + margin 0.05 = 0.280 (pass); accuracy 0.716 vs neutral baseline 0.741 (fail). Condition not met → keep hts5.

_Note: Jev dominates every off-the-shelf candidate on both macro-F1 (0.645) and directional macro-F1 (0.566), and its confusion matrix is far more balanced. It is held back only by hard-label accuracy (0.716) narrowly trailing the constant-neutral baseline (0.741): its extra `bull`/`bear` calls trade some neutral accuracy for directional recall. Under the T3.6 rule both gates must pass, so hts5 is retained; Jev's directional signal is nonetheless worth revisiting at T3.4._
