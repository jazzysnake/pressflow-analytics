## Context

Scraping 10 years ≈ ~15,000 pages. The run must be polite, crash-safe, and
unattended.

## Objective

Crawl pages over the window and write deduplicated posts to Parquet.

## Implementation notes

- Walk **newest → oldest**: from max `oldal` down to the start page from T1.3.
  This lands recent data first (matches "score recent years first" for a fast
  signal check) and makes the checkpoint "lowest completed `oldal`".
- Per request: `requests.Session`, the UA/Accept-Language headers from ADR-0004,
  timeout, retry 3× with exponential backoff on non-200.
- Rate-limit `delay_sec` from config (0.35s default).
- Write incrementally: append parsed pages to Parquet every ~50 pages; update a
  checkpoint file (`data/raw/crawl_checkpoint.json`) after each batch.
- Dedupe on `hsz_id` (natural key); on resume, skip pages already completed.
- Log progress: pages done, posts collected, failures (retryable vs skipped).
- Skip-and-log pages that fail permanently (never crash the whole run).

## Acceptance criteria (DoD)

- [ ] Interrupting mid-run and re-running resumes without gaps or duplicates.
- [ ] Runs ~15k pages unattended and finishes.
- [ ] Posts Parquet matches the `posts` schema (T0.3).
- [ ] No page is fetched more than once per run (checkpoint respected).
