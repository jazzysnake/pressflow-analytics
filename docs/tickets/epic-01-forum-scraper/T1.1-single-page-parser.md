## Context

The forum is server-rendered HTML (`lang="hu"`). One page (`?oldal=N`) contains
~20–24 posts. We must extract structured records from the HTML (markers are
listed in ADR-0004).

## Objective

Parse one saved HTML page into a list of per-post records.

## Implementation notes

- Use `BeautifulSoup` with the `lxml` parser (HTML is large; regex is fragile).
- Commit a real page as a fixture at `tests/fixtures/forum_page.html` (any
  single `oldal=N` response works).
- Extract per post using the markers below; guard every field (some posts have
  no reply-to, no votes).

| Field | Marker |
|---|---|
| author | `a.username` → text |
| raw timestamp | `span.date` → `title` attr |
| display post id | `.id` div → text `#1340744` (strip `#`) |
| hsz_id | vote span `data-hsz_id` attr |
| user_id | vote span `data-user_id` attr |
| reply-to display id | "Előzmény" `a` → anchor text `#1340742` |
| reply-to hsz_id | "Előzmény" `a` → href `/prev/5224/<hsz_id>` |
| upvotes | `span[data-vote="1"] span` → int |
| downvotes | `span[data-vote="-1"] span` → int |
| text | `div.text > div` → inner text (preserve line breaks) |

- Output records match the `posts` schema (T0.3): `post_id`, `hsz_id`, `author`,
  `user_id`, `ts` (raw string here — resolved in T1.2), `reply_to_post_id`,
  `reply_to_hsz_id`, `upvotes`, `downvotes`, `text`, `page`.

## Acceptance criteria (DoD)

- [ ] Unit test on the fixture returns ~20–24 records.
- [ ] Each record has all fields present (nulls only where legitimately absent).
- [ ] `post_id`, `hsz_id`, `upvotes`, `downvotes` are ints; `page` is the
      requested `oldal`.
- [ ] `text` non-empty for ≥95% of records on the fixture.
