## Context

Pages are addressed by `?oldal=N`: `oldal=1` is the oldest page; the newest page
is the highest `oldal` (~67,037 on 2026-10-01 and growing). To scrape "10 years
back" we must find which `oldal` corresponds to a target date.

## Objective

Locate the `oldal` whose newest post is ≥ a target date.

## Implementation notes

- Current max `oldal`: fetch page 1, regex all `oldal=(\d+)` in pagination
  links, take `max + 1` (page 1 has no self-link; links show page 2 = max−1).
  Sanity-check by fetching that `oldal` and confirming it equals page 1 content.
- Within a page, posts are ordered newest→oldest, so **the first post's
  timestamp is the page's newest**.
- Binary search `oldal` in `[1, max]` for the smallest `oldal` whose newest post
  timestamp ≥ target (use T1.2 to resolve).
- Document known checkpoints for tests (verified live):
  `oldal=30000` → 2010-11-25 · 10-year start (target 2016-10-01) = `oldal=50666`
  (newest post 2016-10-03) · `oldal=66773` → 2026-08-18.

## Acceptance criteria (DoD)

- [ ] Given 2026-10-01 and target = 10 years earlier, returns `oldal=50666`
      (exact value verified live; boundary: newest(50666)=2016-10-03 ≥ target,
      newest(50665)=2016-09-30 < target).
- [ ] Correctly handles target older than the oldest page (returns 1).
- [ ] Unit tests using mocked page responses for a small synthetic index.
