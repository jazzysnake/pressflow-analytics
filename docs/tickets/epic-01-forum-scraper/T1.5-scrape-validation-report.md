## Context

Before spending compute on sentiment scoring, confirm the scrape is complete and
clean.

## Objective

Produce a validation report over the scraped Parquet.

## Implementation notes

Report at least:
- posts per page (expect ~20–24; flag outliers),
- date coverage vs target window (first/last date, gaps > 3 days),
- missing-field rates per column (text, ts, author, upvotes…),
- duplicate `hsz_id` count (expect 0),
- posts/day histogram (sanity vs ADR-0004 measured ~100–125 normal days),
- `ts` parse-failure count (from T1.2 `None`s).

## Acceptance criteria (DoD)

- [ ] Report artifact committed under `docs/reports/` (or printed to log).
- [ ] Thresholds enforced: ≥95% posts have non-null `text` and `ts`; 0 duplicates.
- [ ] Any violation blocks Epic 03 and is flagged for review.
