## Context

This is the **first kill gate**. Before any backtest, check whether the crowd
signal has *any* relationship with next-day returns, and in which direction
(ADR-0008: data decides momentum vs contrarian).

## Objective

Measure and visualize the signal→return relationship.

## Implementation notes

- For each signal (`z_score`, `score_wmean`, `disagreement_std`, `entropy`,
  `count`):
  - Spearman **rank-IC** vs next-day `ret_log`,
  - rank-IC vs **negated** returns (the contrarian direction) — report both,
  - **decile buckets**: sort days by signal, plot mean next-day return per
    decile.
- Identify the single best signal+direction; record it.
- Apply kill criterion 1 from ADR-0014: |rank-IC| < 0.05 → **stop and report**.

## Acceptance criteria (DoD)

- [ ] IC table (all signals × both directions) + decile plots in
      `docs/reports/rank-ic.md`.
- [ ] Momentum vs contrarian direction decided from data and recorded.
- [ ] Kill decision documented if |rank-IC| < 0.05.
