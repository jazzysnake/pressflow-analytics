## Context

The tradeable relationship is: signal from day **t−1** posts → return on day **t**
(ADR-0010).

## Objective

Build the aligned signal→return panel with a leakage guard.

## Implementation notes

- Merge `signals` (day d) with `prices` such that the **return of day t** is
  paired with the **signal of day t−1**.
- Next-day return in USD: `ret_log = ln(otp_usd[t] / otp_usd[t−1])` and
  `ret_simple`; label `up = ret_simple > 0`.
- Add an explicit **assertion/test** that the signal row for t−1 contains no
  post with `ts >= t` (join by date only; verify no future date leaks).

## Acceptance criteria (DoD)

- [ ] Merged panel: `date, [signals…], ret_log, ret_simple, up`.
- [ ] Automated leakage test passes (signal strictly uses prior-day posts).
- [ ] Row count equals number of BÉT trading days minus 1.
