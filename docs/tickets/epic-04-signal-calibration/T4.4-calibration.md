# T4.4 — Calibration to P(next-day up)

## Context

The signal must become a probability of next-day up, with uncertainty-aware
shrinkage (ADR-0003, ADR-0009).

## Objective

Produce a calibrated P(up) with shrinkage toward 0.5.

## Implementation notes

- Features: the best signal(s) from T4.3 (+ optional `disagreement_std`).
- Fit **logistic regression** (or isotonic if the relationship is nonlinear)
  mapping signal → P(up day t).
- **Walk-forward / expanding-window scheme**: fit only on data up to t−1 to
  predict t (never fit on the full sample then evaluate) — this is the same
  no-lookahead discipline as ADR-0010.
- Shrink: `p̃ = 0.5 + γ·(p̂ − 0.5)` with `γ = shrink_gamma` from config (default
  0.5).
- Report calibration curve (binned predicted vs actual up-rate) + Brier score.

## Acceptance criteria (DoD)

- [ ] Calibrated probability function, walk-forward, no lookahead.
- [ ] Calibration curve + Brier in `docs/reports/calibration.md`.
- [ ] `p̃` stored per day for the backtest.
