## Context

ADR-0018: calibration should produce a full posterior over P(up) and a
posterior-predictive distribution of next-day return, not a point estimate.
Only pursued if T4.3 shows the signal is not noise.

## Objective

Replace the point logistic with a Bayesian calibration that yields per-day
posterior summaries + `P(return > x%)`.

## Implementation notes

- Tooling: PyMC (or Stan via cmdstanpy). ~2,500 daily observations → fits in
  seconds.
- Features: best signal(s) from T4.3 (+ optional `disagreement_std`).
- Model A (logistic): `up_t ~ Bernoulli(σ(β·x_{t−1}))`, weakly informative
  priors on β → posterior over P(up).
- Model B (returns): `ret_log_t ~ StudentT(μ = α + β·x_{t−1}, σ, ν)` →
  posterior-predictive distribution of next-day return.
- Walk-forward expanding window (fit on data ≤ t−1, predict t); automated
  no-lookahead test (ADR-0010).
- Posterior-predictive: sample next-day returns; compute `P(return > x%)` for
  thresholds {0, +0.5%, +1%} and `P(return > cost)`.
- Store per day: `p_up_mean`, `p_up_sd`, `p_up_lo`, `p_up_hi` (e.g. 5–95%
  credible interval), `p_ret_gt_0`, `p_ret_gt_cost` — consumed by T5.7.

## Acceptance criteria (DoD)

- [ ] Posterior over P(up) + posterior-predictive return distribution per day.
- [ ] Walk-forward, no lookahead (tested).
- [ ] `P(return > x%)` and `P(return > cost)` computed and stored.
- [ ] Brier/log-loss + calibration curve vs the T4.4 point baseline in
      `docs/reports/calibration-bayesian.md`; Bayesian version no worse.
