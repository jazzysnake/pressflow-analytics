## Context

Turn calibrated probabilities into a long-only, costed equity curve
(ADR-0009, ADR-0010, ADR-0012).

## Objective

A config-driven, unit-tested backtest engine.

## Implementation notes

- Signal day t−1 → position day t, close-to-close.
- Position from fractional Kelly (long-only, no short):
  - `p̃ ≤ 0.5` → position 0 (cash),
  - else `position = min(cap, k·(2·p̃ − 1))` with `k = 0.25`, `cap = 1.0`
    from config.
- Costs charged on **turnover**: `cost_t = cost_roundtrip · |position_t − position_{t−1}|`.
- Daily return: `ret_t = position_t · ret_simple_t − cost_t`; compound to equity.
- Implement as a pure function `run_backtest(panel, params) -> backtest_df`
  (easy to unit-test), reading params from config.

## Acceptance criteria (DoD)

- [ ] Unit tests on synthetic data reproduce hand-computed equity/costs.
- [ ] Position always in [0, 1]; cash when p̃ ≤ 0.5.
- [ ] Output matches the `backtest` schema (T0.3).
