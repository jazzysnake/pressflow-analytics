## Context

ADR-0018: size by the posterior, not a point p̂. T5.1 currently consumes a
scalar `p_up`; this extends it to consume the posterior summary and shrink the
position when uncertain.

## Objective

Uncertainty-aware, long-only position sizing from the posterior.

## Implementation notes

- Input: per-day `p_up_mean`, `p_up_sd` (or credible interval) from T4.6.
- Position rule is decision-theoretic: derive the long-only position from the
  posterior so that **wider uncertainty → smaller position** (e.g. expected
  fractional-Kelly under the posterior, or `E[p̃]` shrunk by `p_up_sd`). Exact
  form decided at implementation; must preserve [0, 1], cash when `E[p̃] ≤ 0.5`.
- Reuse T5.1's cost-on-turnover and equity compounding; only the position rule
  changes.
- A/B: run side-by-side with T5.1 point-Kelly on the same panel; report
  after-cost Sharpe and max drawdown for both.

## Acceptance criteria (DoD)

- [ ] Sizing consumes the posterior (uncertainty shrinks position).
- [ ] Position always ∈ [0, 1]; long-only preserved.
- [ ] A/B vs point-Kelly documented in `docs/reports/sizing.md`.
