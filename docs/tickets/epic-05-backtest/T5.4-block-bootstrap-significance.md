## Context

Returns are autocorrelated and the signal is persistent, so naive t-stats lie.
Monte Carlo significance testing is the agreed way to decide if the edge is
real (ADR-0003).

## Objective

Estimate the probability the observed edge is luck.

## Implementation notes

- **Circular block bootstrap** (block length 5–10 trading days, chosen via a
  sensitivity note) resampling *pairs* of (strategy return, SPY return) to
  preserve cross- and auto-correlation.
- Statistic of interest: excess total return and excess Sharpe vs SPY.
- Report the bootstrap distribution and the **p-value** of
  `excess ≤ 0` (i.e., how often a random reshuffle fails to beat SPY).
- Additionally: **permutation test** on the rank-IC from T4.3 (shuffle returns,
  recompute IC) → p-value for the signal relationship.

## Acceptance criteria (DoD)

- [ ] Kill criterion 3 (p > 0.10) evaluated.
