## Context

The repo is empty. Everything downstream needs a runnable Python package with
uv-managed dependencies and a test runner.

## Objective

Create a `uv`-managed project skeleton.

## Implementation notes

- `pyproject.toml` with `requires-python = ">=3.12,<3.13"` (3.14 lacks wheels
  for the ML stack — see ADR-0015).
- Package layout: `src/pressflow/__init__.py`, `tests/`, `notebooks/`,
  `data/` (with `.gitignore` that ignores `data/**` and `*.parquet`).
- Add dependencies as needed by later tickets (do not pre-install everything):
  `requests`, `beautifulsoup4` + `lxml`, `pandas`, `pyarrow`, `yfinance`,
  `transformers`, `torch`, `scipy`, `scikit-learn`, `matplotlib`, `pytest`.
- Configure `pytest` so `uv run pytest` works from the repo root.

## Acceptance criteria (DoD)

- [ ] `uv sync` succeeds.
- [ ] `uv run python -c "import pressflow"` succeeds.
- [ ] `uv run pytest` runs (an empty/smoke test is fine).
- [ ] `data/` contents are ignored by git.
