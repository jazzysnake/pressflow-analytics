## Context

Every downstream module needs the agreed parameters (costs, Kelly, window,
models, paths). Hardcoding them in multiple places will cause drift.

## Objective

One validated config, read by all modules.

## Implementation notes

- `config/default.yaml` (plus optional env override) with at least:

```yaml
forum:
  base_url: https://forum.portfolio.hu/topics/otp-reszvenyesek-ide/5224
  thread_id: 5224
window_years: 10
costs: { base: 0.003, low: 0.0015, high: 0.006 }   # round-trip, fraction
kelly: { k: 0.25, shrink_gamma: 0.5, cap: 1.0 }
models:
  - NYTK/sentiment-hts5-xlm-roberta-hungarian
  - NYTK/sentiment-ohb3-xlm-roberta-hungarian
  - cardiffnlp/twitter-xlm-roberta-base-sentiment
scraping: { delay_sec: 0.35, retries: 3 }
paths: { data: data, raw: data/raw, processed: data/processed }
```

- Loader validates types and ranges (e.g., costs in (0, 0.02), k in (0, 1)) and
  raises a clear error otherwise.
- Expose a single `get_config()` entry point.

## Acceptance criteria (DoD)

- [ ] Config loads from the repo default.
- [ ] Invalid values raise with a clear message.
- [ ] No hardcoded parameters anywhere else — all modules import config.
