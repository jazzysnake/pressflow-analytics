## Context

We need a labeled eval set to pick among off-the-shelf sentiment models
(ADR-0001). Agreed method (supersedes "human hand-labeling"): **no humans** —
label every post with **two independent LLM models** and keep only the posts
where both agree, as consensus ground truth.

## Objective

Produce a ~200-post eval set, evenly distributed across the 10-year window,
labeled bull/bear/neutral (+ sarcasm/panic flags), containing only posts where
both models agreed.

## Implementation notes

- All artifacts go in the **tracked `eval/` directory** (repo root; not under
  gitignored `data/`).
- **Sampling** — use the existing `src/pressflow/forum/pagination.py` (binary
  search) and `parser.py`: pick ~20 evenly-spaced dates across the 10y window
  (2016-10 → 2026-10, every ~6 months), locate each date's `oldal`, fetch 1–2
  pages, and sample ~10 posts per date → ~200 posts. Write
  `eval/sample.csv` with columns `hsz_id, post_id, ts, text`.
- **Model A labeling** (implementer, default model) — label every post
  `bull`/`bear`/`neutral` + `sarcasm`/`panic` booleans → `eval/labels_modelA.csv`
  (columns `hsz_id, label, sarcasm, panic, note`).
- **Model B labeling** (second agent, DIFFERENT model) — same schema,
  independent of Model A's output (must not read `labels_modelA.csv`) →
  `eval/labels_modelB.csv`.
- **Consensus** — keep rows where the two models agree on `label`; record
  `sarcasm`/`panic` where both agree (else null). Write `eval/eval_set.csv`
  (`hsz_id, post_id, ts, text, label, sarcasm, panic`) + report agreement rate
  in `eval/README.md`.

## Acceptance criteria (DoD)

- [ ] `eval/sample.csv` has ~200 posts with `ts` spread evenly across 10y
      (min near 2016-10, max near 2026-10, no >9-month gap).
- [ ] `eval/labels_modelA.csv` and `eval/labels_modelB.csv` each cover all
      200 sampled posts.
- [ ] `eval/eval_set.csv` contains only agreement rows; agreement rate ≥ 60%
      (else expand sample and re-label).
- [ ] All eval files committed to git.
