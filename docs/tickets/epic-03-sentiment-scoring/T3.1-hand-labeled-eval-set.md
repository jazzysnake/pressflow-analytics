## Context

We are not training, but we must *choose* among off-the-shelf sentiment models
(ADR-0001). That needs a small labeled reference set.

## Objective

Label ~100 posts to evaluate candidate models.

## Implementation notes

- Sample ~100 posts **stratified by era** (e.g., ~⅓ each from 2016, 2021, 2026)
  and by thread activity (normal vs high-volume days).
- Labels: `bull` / `bear` / `neutral`. Separately flag `sarcasm` and `panic` as
  boolean columns (these are the known failure modes).
- Have **two labelers on a 20-post overlap**; compute Cohen's kappa.
- Output CSV per T0.3 conventions: `post_id, hsz_id, text, label, labeler, sarcasm, panic, note`.

## Acceptance criteria (DoD)

- [ ] ≥100 labeled posts, stratified as above.
- [ ] Kappa reported; if < 0.6, discuss and re-label the overlap.
