## Context

Score every scraped post with the chosen model. Model = **Jev** (TypeSafe API,
T3.6): calibrated `choice` over {bull, bear, neutral}. ~277k posts, API-only,
~$5 estimated cost. Must be **fast (concurrent)**, **resumable**, and **robust
to transient network errors** without wasting paid tokens.

## Objective

Produce a resumable scores Parquet keyed by `hsz_id`, covering all posts.

## Implementation notes

- Input: `data/processed/posts.parquet`. **Order newest → oldest.**
- **Concurrency**: `ThreadPoolExecutor` with N=16 workers (tunable); respect rate
  limits; reuse the request logic in `src/pressflow/score_jev.py`.
- **Resumability**: checkpoint of completed `hsz_id`s (sidecar JSON + read-back
  of the scores Parquet); flush scores every ~500 completions and on shutdown;
  resume skips already-scored rows.
- **Failure tolerance**: per-post retry (exponential backoff, ~3 attempts) on
  network errors / 429 / 5xx. A post that still fails → append to a
  `failed_hsz_ids` side file and continue. **Abort the whole run only after
  `MAX_CONSECUTIVE_FAILURES = 10` in a row** (configurable); any success resets
  the counter.
- **Cost tracking**: log cumulative input/output tokens, estimated $, throughput
  (posts/sec), and ETA; stop automatically if estimated cost exceeds a cap
  (default `$9`, given a `$10` balance).
- Store per T0.3 `scores` schema: `hsz_id, model, p_bull, p_bear, p_neutral, net`
  (plus `confidence`, `raw_label`).

## Acceptance criteria (DoD)

- [ ] Scores for all posts (no missing `hsz_id`s vs posts table), or a documented
      `failed_hsz_ids` list for the remainder.
- [ ] Resumes correctly after interruption (no duplicate spend on done rows).
- [ ] Runs concurrently (N=16) with throughput, ETA, and cost logged.
- [ ] Transient failures retried; run aborts only after 10 consecutive failures.
- [ ] Total estimated cost ≤ cap, reported at the end.
