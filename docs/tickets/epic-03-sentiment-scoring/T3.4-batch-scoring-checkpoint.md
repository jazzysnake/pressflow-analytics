## Context

Score every scraped post (recent years first, for a fast signal check). This is
the compute-heavy step.

## Objective

Produce a resumable scores Parquet keyed by `hsz_id`.

## Implementation notes

- Input: `posts.parquet` from T1.4. **Order posts newest → oldest.**
- Batch inference (e.g., batch 32) with the chosen model; use GPU if available,
  else CPU (overnight is fine).
- Checkpoint: append scores to Parquet every N batches and write a progress
  file of completed `hsz_id`s; resume skips done rows.
- Store per T0.3 `scores` schema: `hsz_id, model, p_bull, p_bear, p_neutral, net`.
- Log throughput (posts/sec) and ETA.

## Acceptance criteria (DoD)

- [ ] Scores for all posts in the window (no missing `hsz_id`s vs posts table).
- [ ] Resumes correctly after interruption.
- [ ] Throughput/ETA logged so full-window cost is predictable.
