## Context

We evaluate 2–3 pretrained models without fine-tuning (ADR-0001).

## Objective

Score the eval set with each candidate model and normalize outputs.

## Implementation notes

- Candidates (from config):
  - `NYTK/sentiment-hts5-xlm-roberta-hungarian` (5-class)
  - `NYTK/sentiment-ohb3-xlm-roberta-hungarian` (3-class, opinion text)
  - `cardiffnlp/twitter-xlm-roberta-base-sentiment` (multilingual 3-class baseline)
- Load via `transformers` `pipeline("sentiment-analysis", model=...)`.
- Normalize each model's output to `p_bull`, `p_bear`, `p_neutral`:
  - 3-class models map labels directly.
  - 5-class models map {very neg, neg}→bear, {neutral}→neutral,
    {pos, very pos}→bull (sum probabilities within groups).
  - `net = p_bull − p_bear` (in [−1, 1]).
- Store raw labels too, for the selection analysis.

## Acceptance criteria (DoD)

- [ ] Scores for all eval posts × all models in `data/processed/eval_scores.parquet`.
- [ ] `net` in [−1, 1]; probabilities sum to 1.
