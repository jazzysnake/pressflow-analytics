## Context

The off-the-shelf HF classifiers are near-chance on directional sentiment
(hts5 bull confusion row 9-9-9 = random; ADR-0001's "mostly right" bar is not
met). Test Jev — TypeSafe's API-only decision model
(https://docs.typesafe.ai/introduction/quickstart) — which returns calibrated
probabilities over a user-defined option set.

## Objective

Score the 201-post eval set with Jev's `choice` primitive and compare against
the hts5 baseline using the same metrics as T3.3. Decide adopt/reject.

## API facts

- Endpoint: `POST https://api.typesafe.ai/v1/systemone`
- Auth: `Authorization: Bearer <TYPESAFE_API_KEY>`
- Body: `{ "state": <text>, "model": "jev-latest", "questions": {...} }`
- Sentiment via a `choice` question with criteria:
  `bull` = expects price to rise / buy / positive;
  `bear` = expects fall / sell / negative;
  `neutral` = no directional stance (question, bare quote, off-topic).
- Response: `answers.<qid>.choice`, `answers.<qid>.probabilities` (dict summing
  to 1), `confidence`.
- Map `probabilities` → `p_bull` / `p_bear` / `p_neutral`; `net = p_bull − p_bear`.

## Implementation notes

- Load `TYPESAFE_API_KEY` from `.env.secrets` into the environment WITHOUT
  printing/logging the value (python-dotenv or a minimal loader). The file is
  gitignored — never commit it, never echo the key.
- Use raw `requests` (already a base dependency); ~0.2s delay between calls and
  retry on 429/5xx.
- Write scores to `data/processed/jev_scores.parquet`.
- Compute accuracy / macro-F1 / directional macro-F1 / confusion matrix (reuse
  metric code from `src/pressflow/select_model.py`).
- Write `docs/reports/jev-eval.md` with a side-by-side table vs
  hts5/ohb3/cardiffnlp and a clear adopt/reject conclusion.

## Acceptance criteria (DoD)

- [ ] All 201 eval posts scored via Jev; `data/processed/jev_scores.parquet` written.
- [ ] `net ∈ [−1,1]`; probabilities sum to 1.
- [ ] `docs/reports/jev-eval.md` has metrics + hts5 comparison + conclusion.
- [ ] API key never committed, printed, or logged (`.env.secrets` gitignored).
- [ ] Conclusion: adopt Jev if directional macro-F1 clearly beats hts5's 0.230
      (accuracy-vs-neutral gate dropped as misleading on a 74%-neutral set);
      otherwise keep hts5.
