## Context

Pick the single best off-the-shelf model for the full scoring run.

## Objective

Choose a model, with a written justification.

## Implementation notes

- For each model vs labels: accuracy, macro-F1, confusion matrix
  (bull/bear/neutral).
- Specifically inspect misclassified examples flagged `sarcasm` or `panic`
  (from T3.1) — a model that mishandles sarcasm will bias the aggregate.
- Prefer a model that is *calibrated* (confidence roughly matches accuracy),
  since aggregation uses probabilities, not hard labels.
- Write the justification to `docs/reports/model-selection.md`.

## Acceptance criteria (DoD)

- [ ] One model chosen and recorded in config as the default.
- [ ] Justification doc with metrics + example errors.
