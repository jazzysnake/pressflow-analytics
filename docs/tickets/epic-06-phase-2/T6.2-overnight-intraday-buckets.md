## Context

The only intraday granularity we consider is a 2-bucket split (ADR-0007), and
only if the daily signal already shows an edge.

## Objective

Test whether intraday flow adds information over daily.

## Implementation notes

- Bucket posts into **overnight** (prev close → open) vs **intraday**
  (open → close), Europe/Budapest.
- Build separate signals; test overnight sentiment → intraday return and
  intraday sentiment → next-day return.
- Report rank-IC vs the daily baseline.

## Acceptance criteria (DoD)

- [ ] Rank-IC comparison documented; decision on whether intraday adds value.
