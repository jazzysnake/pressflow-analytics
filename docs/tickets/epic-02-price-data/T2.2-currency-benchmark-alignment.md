## Context

The benchmark is the S&P 500 in USD; OTP trades in HUF. Everything must be
compared in a common currency (USD, via `USDHUF`).

## Objective

Build an aligned USD-denominated daily panel.

## Implementation notes

- `otp_usd = OTP.BD Adj Close (HUF) ÷ USDHUF` (USDHUF = HUF per 1 USD) → OTP total return in USD.
- `spy_usd = SPY Adj Close` → S&P 500 total return in USD; also carry `spy_adj_close_usd` (raw series) per the T0.3 schema.
- Normalize the yfinance date index to tz-aware Europe/Budapest midnight
  timestamps (matching the `prices` schema) before writing Parquet — later
  stages join on tz-aware dates, so avoid naive/mixed tz dates.
- Trading calendar = days where `OTP.BD` has a bar (BÉT). Join all series onto
  this calendar; drop rows where OTP has no bar.
- Forward-fill `USDHUF` for any BÉT day missing an FX quote (rare), and log it.
- Output the `prices` schema from T0.3.

## Acceptance criteria (DoD)

- [ ] Panel has no NaN on valid BÉT trading days.
- [ ] Columns (8, per T0.3 schema): `date`, `otp_close_huf`,
      `otp_adj_close_huf`, `usdhuf`, `spy_adj_close_usd`, `spx_close`,
      `otp_usd`, `spy_usd`.
- [ ] A spot check confirms `otp_usd` moves on a day when both OTP and USDHUF
      moved as expected.
