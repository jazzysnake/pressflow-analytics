## Context

Price data is the benchmark and the trading target. `yfinance` was verified to
work (uv, Python 3.12) for all needed tickers.

## Objective

Download daily price history into Parquet.

## Implementation notes

- Tickers: `OTP.BD`, `SPY`, `USDHUF=X`, `^GSPC`.
- Range: window start − 1 year (buffer for the rolling z-score) → today.
- Use `yf.download(..., auto_adjust=False)` so both `Close` and `Adj Close` are
  preserved (total-return logic in T2.2).
- Store raw columns; make the date index a tz-aware column.

## Acceptance criteria (DoD)

- [ ] Parquet at `data/raw/prices.parquet` with all four tickers.
- [ ] Date index tz-aware; row counts and first/last dates printed for sanity.
- [ ] Gaps exist only on non-trading days.
