## Context

Dividend handling in `Adj Close` is a known simplification and can be wrong for
less-covered tickers like `OTP.BD`.

## Objective

Check the price data for adjustment anomalies and document caveats.

## Implementation notes

- Compare `Adj Close` vs `Close` for OTP: jumps in the ratio indicate dividend
  adjustments; list dates and approximate yields.
- Sanity-check `USDHUF` levels against known history.
- Flag any yfinance gaps/zero rows.

## Acceptance criteria (DoD)

- [ ] Report listing dividend-adjustment dates + magnitudes for OTP.
- [ ] Caveats appended to ADR-0011 (Benchmark) §consequences.
